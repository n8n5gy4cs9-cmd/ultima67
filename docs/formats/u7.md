# Ultima 7 data files used by the importer (T4.2/T4.3)

You provide your own legally-owned copy; nothing from it is ever committed (`assets/original/` is git-ignored).
Copy the contents of your install's `STATIC` folder (any letter case) to `assets/original/u7/`, then:

```bash
cargo run --release -p u67_import --bin import_u7            # reads assets/original/u7, writes assets/maps/*.u67map
cargo run --release -p u67_import --bin import_u7 -- --dump-rules rules.json   # edit keywords, then pass --rules rules.json
```
The game loads `assets/maps/midgard.u67map` (plus the cave maps the importer generates) instead of its procedural Midgård. Delete the files to go back.

## Files read
| File | Meaning |
|---|---|
| `u7map` | 12x12 superchunks x 256 little-endian u16 chunk-template ids (row-major inside a superchunk) |
| `u7chunks` | chunk templates: 256 tiles x 2 bytes; shape = b0 + 256*(b1&3), frame = (b1>>2)&0x1f |
| `u7ifix00`..`u7ifix8f` | Flex per superchunk; entry `cy*16+cx` = 4-byte fixed objects: `[tx<<4|ty][lift&15][shape lo][shape hi&3 | frame<<2]` |
| `shapes.vga` | Flex; shapes < 0x96 are flat 8x8 tiles, 64 raw palette bytes per frame (we average them to classify the terrain) |
| `palettes.flx` | entry 0 = 256 RGB triplets, 6 bits per channel |
| `text.flx` | entries 0..0x3ff = shape names (NUL-terminated) - used for the name rules |
| `tfa.dat` | 3 flag bytes per shape: `[0]&8` solid, `[0]&16` water, `[1]&32` door, `[2]` x/y dims, `[0]>>5` height |
| Flex | 80-byte title, u32 0xffff1a00 @0x50, u32 count @0x54, entry table (offset,len) u32 pairs @0x80 |

## What the conversion does
1. **Terrain**: each flat tile becomes a Midgard tile by average colour + the water flag (blue → water, green → grass/forest, white → snow, yellow → sand, brown → road, grey → rock/mountain, ...).
2. **Objects** by shape name (rules JSON): trees → pine/birch, chests, barrels, beds, tables, wells, signs, forges, cannons, doors...; unnamed tall solid shapes → stone walls; high-lift solid shapes → roofs.
3. **Buildings**: roof tiles are grouped into buildings (roofs hide when you step inside).
4. **Norse transformation**: town clusters are detected and renamed to Midgard's towns (largest = Kaupang, northern ones = Rovala/Helgate/Kuusamo/Reyk...), each gets the standard places (`<town>_house_1..4`, `_market`, `_tavern`, `_forge`, `_dock`) so NPC schedules work; missing towns are generated procedurally; the north becomes snowy; then rune rings, camps, wolf dens, the Kaupang gate, Jörmungandr's nest and the cave dungeons are added (same code as the generator).

Because this was written without access to a real install, expect to tune `rules.json` (name keywords, wall height) against your data; the unit tests use synthetic files.
